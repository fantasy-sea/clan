# clan(家‘助’)
> 获取被控手机屏幕内容，控制方可以远程操作被控手机
## 项目背景
>当父母不会操作 Android 手机时，子女可以通过自己的手机远程看到父母手机的实时画面，并帮助父母完成点击、滑动、返回、Home 等操作，从而远程解决手机使用问题。
## 功能特性
- 实时远程操作 （受限于网络环境）
- 被控方、控制方身份一键切换
## 快速开始
### 设备要求
- Android版本>=12

## 技术说明
> MediaProjection（获取屏幕内容） WebSocket+WebRTC   AccessibilityService(无障碍服务)   AccessibilityServiceInfo(无障碍服务信息)
